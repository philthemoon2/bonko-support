## BONKO Streamer 2.1.0 for macOS and Windows

BONKO Streamer is now available as a free 64-bit VST3 for macOS and Windows.

- New MONO ON/OFF output for both DAW output and iPhone/iPad stream
- Mono state is saved and restored with the DAW project
- Universal Apple Silicon + Intel macOS VST3
- Native Windows 10/11 x64 VST3
- Complete ZIP packages with installer, uninstaller, README, license, and
  SHA-256 checksums
- Processor, project-state, local-server, automation, GUI, sample-rate, and
  block-size validation

The macOS package is Apple-signed, notarized, stapled, and Gatekeeper-accepted.

The Windows setup is not yet Authenticode-signed. Windows SmartScreen may show
an “unrecognized app” warning. Download only from the official page or this
release and verify its checksum.

Logic Pro and GarageBand do not load VST3; an Audio Unit is not included.

Product and setup guide: <https://bonko.phil-thebeat.com/>
