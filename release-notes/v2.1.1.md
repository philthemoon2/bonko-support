## BONKO Streamer 2.1.1 for macOS

BONKO Streamer now includes an Audio Unit for Logic Pro and GarageBand in the
same free macOS installer as the VST3.

- Universal Audio Unit v2 for Apple Silicon and Intel
- Universal VST3 for compatible macOS DAWs
- One-click mono output for both DAW output and phone stream
- Mono state saved with the host project
- Developer ID signed, Apple notarized, and Gatekeeper accepted
- Audio Unit passed Apple's `auval` and pluginval strictness 10
- VST3 passed pluginval strictness 10

The Windows 2.1.0 package remains the current Windows download while the 2.1.1
release pipeline waits for a trusted Authenticode publisher identity.
