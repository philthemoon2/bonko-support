## BONKO Streamer 2.1.1 for macOS and Windows

BONKO Streamer now includes an Audio Unit for Logic Pro and GarageBand in the
same free macOS installer as the VST3.

- Universal Audio Unit v2 for Apple Silicon and Intel
- Universal VST3 for compatible macOS DAWs
- One-click mono output for both DAW output and phone stream
- Mono state saved with the host project
- Developer ID signed, Apple notarized, and Gatekeeper accepted
- Audio Unit passed Apple's `auval` and pluginval strictness 10
- VST3 passed pluginval strictness 10

The Windows release adds a native x64 VST3 and a guided NSIS installer:

- Native Windows x64 VST3 with the same MONO control and state recall
- VST3, setup, and installed uninstaller signed by verified publisher
  `Philipp Bednorz` through Microsoft Azure Artifact Signing Public Trust
- Every signature uses SHA-256 and a Microsoft RFC-3161 timestamp
- Windows processor and local-server regression suite passed
- Windows VST3 passed the pluginval host-compatibility baseline at strictness 5
- Silent install, installed-file signature checks, and silent uninstall passed

Use `BonkoStreamer-v2.1.1-Windows-Setup.exe` for the direct installer or the
Windows ZIP when you also want the README, license, helper uninstaller, and
checksums.
