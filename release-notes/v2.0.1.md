## BONKO Streamer 2.0.1 for macOS

This is the current free BONKO Streamer VST3 installer for macOS.

- Universal Apple Silicon and Intel VST3
- Signed with Developer ID and notarized by Apple
- Validated in a VST3 host at 44.1, 48, and 96 kHz
- Installer and internal plug-in version aligned to 2.0.1
- Installer guidance now matches the BONKO iPhone/iPad companion workflow
- Stable plug-in identity retained so existing DAW sessions continue to find it

Install path:

`/Library/Audio/Plug-Ins/VST3/Bonko Streamer.vst3`

The current release is VST3 for macOS. Logic Pro does not load VST3 and is not
supported by this installer.
